# SDC435L Group Project

## GitHub Archive Redis Application

This project is a Python application that connects to a Redis key-value database and works with GitHub Archive repository data.

### Features

- Import GitHub Archive JSON data into Redis
- Create repository records
- Read repository records
- Update repository records
- Delete repository records
- Display the most watched repositories
- Search repositories
- Display repository statistics
- Display the total number of Redis records

### Technologies Used

- Python
- Redis
- JSON
- GitHub

### Dataset

The application uses GitHub Archive JSON data. The dataset contains repository information, including repository names and watch counts.

### Project Files

- `GroupProject.py` - Main menu for the Redis JSON application
- `redis_integration.py` - Python application used to connect to Redis and perform database operations
- `README.md` - Project documentation
